# Industrial Sandbox Simulation (C# / .NET)

Консольное приложение, эмулирующее логику работы промышленных узлов автоматизации: проверку софтовых лимитов позиционирования, расчёт времени перемещения по кинематике, валидацию углов сочленений 6-осевого робота и работу конвейерной сортировочной линии технического зрения с обработкой аварийных состояний.

---

## ⚙️ Основной функционал

Проект разбит на независимые функциональные модули (программы):

1. **Модуль контроля рабочей зоны (SW Limits):**
   * Валидация перемещения каретки/манипулятора по оси X в диапазоне `[-500.0, 500.0] мм`.
   * Вычисление величины выхода за пределы рабочей зоны при превышении допустимых границ.

2. **Кинематический расчёт перемещения:**
   * Расчёт расчётного времени движения по заданной дистанции и скорости (`V > 0`, `S > 0`).

3. **Валидация кинематики 6-осевого робота-манипулятора:**
   * Проверка граничных углов для осей A1–A6 с защитой от ввода некорректных значений.
   * Поиск оси с максимальным абсолютным отклонением от нулевой позиции.
   * Подсчёт количества осей, находящихся в положительной полуплоскости.

4. **Конвейер контроля качества и отбраковки (Quality Gate):**
   * Реализация конечного автомата состояний линии (`Idle`, `Scanning`, `Accepted`, `Rejected`, `Emergency`).
   * Классификация деталей по допуску:
     * **Годная деталь:** размер 50 ± 1 мм.
     * **Брак (сброс в корзину):** отклонение в пределах диапазона $40..60$ мм.
     * **Аварийный останов (E-Stop):** критический выход за габариты с немедленной блокировкой конвейера.
   * Сбор истории партии деталей в коллекцию `List<PartReport>` и вывод сводной статистики по завершении цикла.

* **Язык:** C# (.NET 8 / .NET 9)

  * Обработка пользовательского ввода с нормализацией локали (`CultureInfo.InvariantCulture`) и защитой от падений.
  * Коллекционные выражения (Collection Expressions).
  * Строгая типизация через перечисления (`enum`) и DTO-классы.
